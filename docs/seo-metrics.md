# AI×DX Weekly SEO・収益メトリクス

> 月1回、Search Console（とAdSense承認後はAdSense）の数値を転記する記録簿。
> 目的は「先月と比べてどう変わったか」を残すこと。数値そのものより**差分**が判断材料になる。
> **記録日：毎月1日前後（月初）／所要時間：約10分**

---

## 転記の手順（毎回これだけ）

### A. 検索パフォーマンス

1. Search Console 左メニュー「**検索パフォーマンス**」を開く
2. 期間を「**過去28日間**」に設定
3. 上部の4つの指標カードをすべてONにする
   - 合計クリック数 / 合計表示回数 / 平均CTR / 平均掲載順位
4. 下の「**クエリ**」タブ → 上位5件を転記
5. 「**ページ**」タブ → 上位3件を転記

### B. インデックス状況

6. 左メニュー「**インデックス作成 > ページ**」を開く
7. 「インデックスに登録済み」と「未登録」のページ数を転記

### C. AdSense（承認後のみ）

8. AdSenseホーム → 期間「先月」で、推定収益・ページビュー・ページCTR・ページRPMを転記

> **注意**：Search Consoleのデータは反映に数日かかる。月初に見ると直近分が欠けるので、
> 「過去28日間」の固定期間で毎回そろえること。期間をそろえないと比較できなくなる。

## 読み方の指針（迷ったとき用）

| 症状 | 見るべき数値 | 考えられる原因 |
|---|---|---|
| 表示回数が伸びない | インデックス登録済み数 | そもそも検索対象になっていない／コンテンツ量不足 |
| 表示回数はあるがクリックが少ない | CTRと掲載順位 | 順位が低い（10位以下）か、タイトル・説明文の訴求不足 |
| 掲載順位は良いのにCTRが低い | 上位クエリの中身 | 検索意図と記事内容のズレ |
| PVはあるが収益が低い | ページRPMと広告位置 | 広告配置／記事の滞在時間 |

**判断の原則**
- 1か月の変動で結論を出さない。最低3か月の傾向で見る
- 複数の施策を同月に打つと、何が効いたか分からなくなる。できれば月1〜2施策に絞る
- 「施策」欄を必ず埋める。これがないと数値変化の理由を後から追えない
